About This Blog

📌 Our Mission

This blogging platform is built using Django to share useful knowledge, ideas, and experiences. The goal of this website is to provide a simple platform where users can read and create posts easily.

📝 What You Can Do Here

• Read interesting blog posts
• Create and publish your own posts
• Upload images with posts
• Edit or delete your posts
• Search posts easily

⚙️ Technologies Used

This website is built using:
• Django (Backend Framework)
• HTML & CSS (Frontend Design)
• SQLite Database
• Django Authentication System
